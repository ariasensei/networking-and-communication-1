Big Idea

When you download a file, data may pass through different types of media before reaching your device.

Laptop → Wi-Fi → Access Point → Ethernet Cable → Switch → Fiber → ISP → Internet Server

Data needs a physical or wireless path to travel.

What Is Network Media?

Network media is the physical or wireless channel used to carry data signals between devices.

Data

The vehicle

Network Medium

The road used by the vehicle

Examples: Ethernet cable, coaxial cable, fiber optic cable, Wi-Fi, cellular, microwave, satellite.

Two Main Types of Media

Guided Media

Signals travel through a physical path.

Examples: UTP cable, coaxial cable, fiber optic cable.

Unguided Media

Signals travel through air or space.

Examples: Wi-Fi, Bluetooth, cellular, microwave, satellite.

What Is Physical Transmission?

Physical transmission is the actual movement of data signals through a transmission medium.

MediumSignal Used
Copper cableElectrical signals
Fiber optic cableLight pulses
Wi-Fi / CellularRadio waves
SatelliteRadio or microwave signals

Bits Become Signals

Computers use binary data: 0 and 1.

Copper

Bits are represented by electrical signaling.

Fiber

Bits are represented by light pulses.

Wireless

Bits are encoded onto radio waves.

Guided Media: Wired Transmission

Twisted Pair

Common LAN cable.

Coaxial

Used in cable Internet, CCTV, RF systems.

Fiber Optic

Uses light for high-speed and long-distance links.

Twisted-Pair Cable

Twisted-pair cable contains pairs of copper wires twisted together.

The twisting helps reduce electromagnetic interference and crosstalk.

PC → UTP Ethernet Cable → Switch

Real-world example: University computer laboratory with 30–40 desktop computers.

UTP and Shielded Twisted Pair

UTP

Unshielded Twisted Pair

  • Affordable
  • Easy to install
  • Common in offices and schools

Shielded Twisted Pair

Has extra shielding against interference.

  • Useful near electrical equipment
  • Needs proper installation

RJ45 / 8P8C Ethernet Connector

Ethernet patch cables commonly use what people call an RJ45 connector.

More precisely, many Ethernet patch cables use an 8P8C modular connector.

PC NIC → Ethernet Cable → Wall Jack → Patch Panel → Switch

Coaxial Cable

A coaxial cable has a center conductor, insulation, shielding, and an outer jacket.

Center Conductor → Insulator → Metallic Shield → Outer Jacket

Common uses: cable television, cable Internet, CCTV, and RF systems.

Fiber-Optic Cable

Fiber-optic cable carries information using light.

Core → Cladding → Protective Layers → Outer Jacket

The core carries light, while the cladding helps keep light inside the core.

Why Use Fiber?

High Capacity

Supports very high data rates.

Long Distance

Excellent for backbone and inter-building links.

EMI Resistance

Not affected by electromagnetic interference like copper.

Security Advantage

Does not radiate signals like copper, but still needs protection.

Single-Mode vs Multimode Fiber

Single-Mode Fiber

Used for longer distances, telecom networks, ISP links, and campus backbones.

Multimode Fiber

Used for shorter links in buildings, campuses, and data centers.

Single Mode = longer distance. Multimode = shorter-distance high-speed links.

Campus Network Example

Inside a building, computers may use Ethernet. Between buildings, the campus may use fiber.

Building A Switch → Fiber → Building B Switch → Fiber → Building C Switch

Real-World Wi-Fi Problem

A classroom has one access point. Students nearby have strong signal. Students several rooms away experience slow Internet.

Possible Causes

  • Distance
  • Concrete walls
  • Metal structures
  • Channel congestion

Other Causes

  • Too many users
  • Poor AP placement
  • Interference
  • Weak equipment

Important Wi-Fi Lesson

Having Wi-Fi does not automatically mean having good Wi-Fi.

Wireless network design matters.

How Do We Evaluate Network Media?

Bandwidth

Capacity of the link.

Throughput

Actual useful data transferred.

Latency

Delay in data travel.

Distance

How far signal can travel.

Interference

How easily signal is disturbed.

Cost

Equipment and installation expense.

Bandwidth vs Throughput

Bandwidth

The maximum capacity. Like road lanes.

Throughput

The actual achieved data rate. Like actual traffic movement.

A 1 Gbps link may deliver less actual throughput because of overhead, congestion, interference, or device limits.

Latency

Latency is the delay for data to travel from one point to another.

Low latency is important for online gaming, video conferencing, voice calls, and real-time applications.

Attenuation

Attenuation means the signal becomes weaker as it travels.

Strong Signal → Medium Signal → Weak Signal

That is why cables and wireless links have distance limitations.

EMI, Crosstalk, and Noise

EMI

Interference from electrical devices.

Crosstalk

One channel affects another channel.

Noise

Unwanted signal energy.
