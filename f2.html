📖 Command Quick Reference

ipconfig /allShows IP address, subnet mask, gateway, DNS, and DHCP details.
ping [host]Tests simulated reachability and reports round-trip time.
tracert [host]Displays simulated router hops to a destination.
nslookup [domain]Tests simulated DNS name resolution.
arp -aDisplays the simulated IP-to-MAC address table.
route printDisplays the simulated IPv4 routing table.
netstat -anShows simulated network connections and listening ports.
hostname / getmacDisplays the computer name or simulated MAC address.
For classroom practice only. Example IP ranges and example.com are used as educational sample values. On real Windows CMD, output will differ depending on your device and network. No real network diagnostics are performed by this page.
